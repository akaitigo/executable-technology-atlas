関数の値と、本体の型判断

実行時は関数を呼ぶまで本体を還元しません。型判断は、まだ値を渡していないparameterに型を仮定して、本体を調べます。Γは名前→型、実行環境は名前→値で、二つは別の役割です。

規則今回の意味
T_Int / T_Var整数の型Int / Γから変数の型を読む。
T_Fnparameter型をΓに加え、本体型からArrowを合成する。
T_Call関数がArrowで、引数型がdomainに一致するとcodomainを得る。
T_Add左右ともIntのときだけIntを得る。
