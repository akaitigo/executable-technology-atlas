05実務で判断するときの境界

まず「現在どの集合を処理しているか」「確認済み flag」「その組に確認必要な資源があるか」を分けます。確認待ちは、削除 API が失敗した状態や Health 待ちと同じではありません。

後続 wave の確認状態、flag の生成・認可、annotation/default の解析、Prune=false、pruneObject、実削除、Health、hook、retry、finalizer は模型外です。helper 結果は仮定のままです。

この画面で予想が外れたり未選択の入力エラーになったりしても、Argo CD の失敗を実測したことにはなりません。
