3. 原典と実装をたどる
このpilotは、自前で最小定義したorg.jetbrains.annotations.NotNullをJava宣言に付けています。Kotlin側でどう利用し、Javaの実装が何を返すかを分けて読みます。


最小annotation定義 ／ Java実装 ／ Kotlin利用側 ／ 拒否例


Kotlin公式固定原典：nullability annotationsでは、注釈付きJava型をnullable/non-nullable型として扱う説明を確認できます。元の収集コードは、保存した判定の意味を読むための参照です。この教材では実行しません。


既存cacheにはJetBrainsのannotation jarもありますが、このpilotの使用依存とは異なります。jar確認を、そのjarで実行した証拠へ読み替えません。

C. コードと記録から説明できること
実務では、annotationの宣言と、外部実装がその契約を守るかを別に確認します。今回の拒否例はKotlinからnullを渡す呼出しであり、Java内部の戻り値に対する実行時保証ではありません。


完全なstack trace・javap全文・元の実行時刻は表示できません。原票のbytecode判定は特定の呼出し順や文字列の有無を調べたもので、全経路を証明しません。@Nullable、JSpecify、generic型引数、他compiler版、JVM以外はこの教材の検証範囲外です。
