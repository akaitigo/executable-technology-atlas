3. 正常系と誤実装を比較する
同じ n,budget のまま本体を切り替えて実行する。正常系は y+=1、誤実装は y+=2。どちらも x は減るが、事後条件は異なる。
budgetは全本体の回数。「本体を1回進める」はbudgetを1増やして初期状態から再実行する。途中で保存した可変状態を続行する操作ではない。


4. 紙上の導出を読む
初期化
x=n,y=0
x+y=n
→
保存
I ∧ x>0 ⇒ x≥1
x'=x−1：和 n−1（途中）
y'=y+1：和 n（境界）
→
出口
I ∧ ¬(x>0), x∈ℕ
⇒ x=0 ⇒ y=n


誤実装は本体末尾の和が n+1 となり保存に失敗する。正常系の途中は n−1。誤実装の途中が偶然 n になることもあるが、検査点ではない。


停止は別の論証
V=x は自然数。本体開始時 x>0、本体後 x'=x−1<x。自然数の無限の厳密下降はない。よってbudgetを付けない両方のループは停止する。これは本教材の紙上の数学的論証。Hoareの部分正当性規則だけでは停止を証明しない。


有限の n=0..8 の追試は任意の自然数への機械証明ではない。budget不足はループの非停止を意味しない。n=0,budget=0 は guard exit、n>0,budget=0 は本体未観測。
