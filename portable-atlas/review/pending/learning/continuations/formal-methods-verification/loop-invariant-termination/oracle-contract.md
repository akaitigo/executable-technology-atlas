# 実行前の独立 oracle

手表は n=0,1,3 の文字通りの状態列。閉式は k=min(n,budget)、s=1 または 2 として、境界 x=n−k,y=s·k、途中 x=n−k−1,y=s·k。境界和 n+(s−1)k、途中和 n+(s−1)k−1。

guard exit は k=n。境界違反は (s=2 かつ k>0)。guard exit のときだけ事後条件 s·n=n を評価する。budget=0,n>0 では不変条件の初期化のみ観測し、事後条件は未観測。

checker は反復代入を再利用せず、閉式で全162入力の状態列を組み立てる。手表に続いて実装を書き、checker は実装の計算関数を oracle として使わない。
