# 学習ルート

1. 正常n=3,budget=3を選び、境界を保つか予測する。
2. budget=0に編集して、事後条件が未観測となる理由を述べる。
3. 本体を1回進める。途中の和n−1と、末尾の和nを読み分ける。
4. 同じn,budgetで誤実装へ切り替える。末尾の和n+1と、減少するxを比べる。
5. n=0,budget=0ではなぜ空実行で終了するか考える。
6. 紙上導出の初期化・保存・出口と、別の停止variant論証を読む。
7. 原典、反復代入実装、閉式checker、先に固定した手表へ進む。
8. 答えを開き、予測と分類だけでなくcompletionとpostconditionを確かめる。

到達点：途中の一時的な崩れを境界違反と言わず、budget不足を非停止と言わず、部分正当性を停止証明と言わない。
