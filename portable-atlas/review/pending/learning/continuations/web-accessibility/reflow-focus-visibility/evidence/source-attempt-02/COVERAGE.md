# 範囲と未教材

4条件、5controlずつ20回のTab移動。通常幅1000と320 CSS px、両高さ800。document/viewport/scroll寸法、focus枠style、中心hit-test、全control rect、native AX、captureを保存。故障版の横overflowと送信遮蔽、流動版の狭幅単列を比較。予想、送信Enter、入力reset、503、古い保留結果も記録する。

viewport縮小はzoomではない。実zoom・contrast・forced colors・touch・実AT・mediaは未測定。短いform以外、長文/例外table/入れ子overlay/mobile/fullWCAGは未教材。DOM overlapは幾何的推定、captureの視認と分離。既存scope/学習経路の状態は変更しない。
