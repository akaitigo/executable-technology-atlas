# 原典・版・読む箇所

2026-10-06 JST取得。両Understanding頁の更新表示は2026-09-06。WCAG2.2の解説資料で、規範本文そのものではない。第三者本文・図・code例をコピーせず、独自の短いformを使う。

- [Reflow SC1.4.10](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)、SC/Intent/Overlap: 狭い表示で情報・機能を辿る。二次元layoutを必要とする例外は部分に適用する。viewport幅と実zoomを分け、sticky/fixedによる遮蔽も別に見る。
- [FocusVisible SC2.4.7](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)、SC/Intent/Examples: キーボードfocusの位置を認識できるmodeが必要。focus indicatorはoutlineだけとは限らない。

Modal E3にはzoom/contrast/touch等も残る。今回4条件がその全範囲やWCAG全体を満たすとは扱わない。
