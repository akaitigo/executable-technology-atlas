トークンはどこまで届く？

同じbutton APIで、親へ置いたinstance色が隣へ漏れる実装と、A自身だけに置く修正版を比較します。CSS変数は継承するため、名前にinstanceと書くだけでは隔離されません。

学ぶ順番と実務判断

前提：HTML button、CSS selector・継承、JavaScript event。主要概念：テーマのsemantic token → componentの消費 → instance override → computed value → native disabled/keyboard。

予想→操作→表示とcomputed style比較→所有図/実装/原典→答えの順で進みます。今回から判断できるのは、上書きの所有範囲、APIでの色値検証、disabled属性の利用。hex以外も製品で必要なら型/APIを別途設計してください。CSSの不正値処理は自動的な安全装置ではありません。
