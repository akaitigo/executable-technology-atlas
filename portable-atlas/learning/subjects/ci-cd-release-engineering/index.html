ci-cd-release-engineering / synthetic local release state

そのtestは、どのbytesを検査した？

test → candidate → promotion → rollbackをPythonで実計算。合成artifactの実bytesとSHA-256、拒否後のactive、旧releaseを比べます。

外部CI、registry、deployment、Git操作は行いません。digest一致は同じbytesの確認で、署名・builder信頼・実サービス健全性の証明ではありません。

学習の道筋

前提：bytes・hash・状態遷移 → artifact / test binding / candidate → promotion gateとrollback history → 正常／差替え／failed test／初回releaseを比較 → 実務判断に足りない信頼・並行性・migration → 公式locator。

今回判断できるのは「passed testを別bytesへ流用していないか」「拒否後にactiveを変えていないか」「旧bytesがあるか」です。外部CIの安全性や実deployの復旧は判断できません。
