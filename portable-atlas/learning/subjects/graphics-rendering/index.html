4. 規則・実装・一次資料
座標は右が+x、下が+y。sampleはpixel中心(x+½, y+½)。頂点順を正の面積へ正規化し、各edgeの内側を判定する。辺上はtop-left規則（上向きの辺、または右向きの水平辺）だけ含む。共有辺は一方だけに所属する。
barycentric重みからscreen-linearなzを計算。初期depthは∞（JSONではnull）、新しいzが厳密に小さい場合だけ更新する。等しいzは先勝ちなので、同じ深さの重なりは描画順に依存する。面積0は描画しない。grid外のsampleは検査せず、viewport内だけを走査する。
world→clip変換、homogeneous clipping、perspective-correct補間、有限精度depth、MSAA、shading、cullingは実装していない。有理数の正確計算と実GPU数値精度は同一ではない。
  • Microsoft / Direct3D rasterization rules — pixel中心とtop-left規則の参照。GPU/APIの完全再現は主張しない。
  • Microsoft / Depth Buffers — depth値の保存・比較を参照。教材のzは単純なscreen-linear値。
