1. 予想する

反復で比較する未確定のindexは [lo, hi)。下限の挿入位置pの候補は lo ≤ p ≤ hi で、hiも含みます。値の一致は終了後に別確認します。

3. 線形探索と操作数を比べる
比較数は配列要素に対する値比較だけです。二分探索は反復の<比較と、終了後の一致確認を別に数えます。ソート済確認の隣接比較は別欄に表示。図描画・不変条件診断の全走査・配列コピーは含めません。実行時間のベンチマークではありません。
16件・目標なしと、16件・先頭一致を比べてください。先頭一致では線形探索が1比較で終わります。未整列列にも線形探索は使えますが、二分探索には順序の前提が必要です。実運用で毎回ソート済確認する場合は、そのO(n)のコストも含めて選びます。

4. 実装と一次資料へ戻る
lo = 0; hi = a.length;
while (lo < hi) {
  mid = lo + Math.floor((hi - lo) / 2);
  if (a[mid] < x) lo = mid + 1;
  else hi = mid;
}
// lo は最初の a[i] >= x の位置。該当なしなら n。
// 値の存在は lo < n && a[lo] === x で別に確認。

5. 操作後の答え合わせ
不変条件は 0 ≤ lo ≤ hi ≤ n、i < lo の値は x 未満、i ≥ hi の値は x 以上です。求める下限位置pはloからhiまで（hiを含む）にあります。[lo, hi)の要素だけに目標値が残る、という不変条件ではありません。整列済なら、a[mid] < x のときmidも候補から外せるのでlo = mid + 1。それ以外はmidを右側の境界にできるためhi = midとします。
異常Aはhi = mid - 1とし、まだ左側に確定できない値を誤って右側へ送ります。1,3,5で3を探すとindex 1の候補を失い、不変条件が破れ、見つからないという誤答になります。両端を含む方式の更新を混ぜたことが原因です。
異常Bは長さ1の候補でlo = midとして範囲を変えません。不変条件が成立しても停止性は保証されません。hi - loが毎回減る証明が必要です。教材の診断器は非進捗を検出して停止し、本当の無限ループをBrowserへ放置しません。
重複は最初のindexへ寄せます。空列は0反復・挿入位置0・一致なし。未整列の3,1,2を強行すると3を見落とします。入力を黙って整列させず、前提と失敗をそのまま観察します。
自分の言葉で：①hiはどの候補に含む？ ②[lo, hi)が空なら「なし」が必ず確定？ ③停止と正答を別に説明できる？ ④いつ線形探索を選ぶ？ 答え：①反復のindexには含まないが、挿入位置pの候補には含む ②挿入境界が確定し、一致は別確認 ③不変条件と範囲長の減少を説明する ④小さい列・先頭近く・未整列・単発検索など、準備費用も含めて選ぶ。
