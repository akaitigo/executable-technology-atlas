4 原典と実装を照合する
この教材はCommonMark全体のparserやOpenAPI生成器ではありません。明示HTML anchorと限定されたfenced codeを使い、認識できた例だけを実行します。任意入力コードの実行は受け付けません。
  • Python doctest: 実行例と期待出力の照合 — 本教材はdoctestを呼ばず、限定snippetをsubprocessで実行。
  • CommonMark: fenced code blocks — fenceは文書構文。関数の正しさは別検査。
  • W3C SVG: svg要素 — 実SVGを生成・XML構造検査・表示。
  • ADR: 判断と根拠の記録 — 次の実験に残す未教材分野。
ローカル実装: model.py / api.py / oracle.py。CLIと保存生成物の入り口はREADME.md。HTTPは専用UI/APIのみ公開します。


5 答えと実務判断
古い文書はsource digestで拒否。再生成後は上限8の実stdoutまで照合。hashを更新しても壊れたanchorは検出します。誤った期待値は再生成しても実行結果が一致しません。生成成功・完全性・意味の正しさを一つの「成功」に混ぜないことが実務の判断です。
今回は2関数・8例の教材。SHA-256は改変検知で、署名や信頼できる配布者の証明にはなりません。schemaのAPI意味や図の設計妥当性はレビューが必要です。
