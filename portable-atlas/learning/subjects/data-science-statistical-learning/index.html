04 原典と実装 → 05 答え合わせ
holdoutを使えば、役割も変わる


OLSはfitに渡した点の残差平方和を最小化する。評価点をfitや選択へ戻すと、その点に合わせた数値になる。ここで低下するMSEは、現実の新しいデータの性能を保証しない。


既定データの答えを見る
正常経路は切片1・傾き9/5、train MSE 8/25、holdout MSE 108/25。混入fitは切片2でholdout MSE 33/25。holdout選択は切片3（offset2）で8/25。しかし後者2経路のholdoutは、もう学習・選択と独立ではない。固定追加評価のMSEも選択経路で260.16あり、toy上の小さいholdout誤差をそのまま外へ持ち出せない。


OLS式と独立oracleの違い
production: b = Σ[(x−x̄)(y−ȳ)] / Σ[(x−x̄)²]
            a = ȳ − b x̄     (float / math.fsum)
oracle:     D = n Σx² − (Σx)²
            a = [(Σy)(Σx²) − (Σx)(Σxy)] / D
            b = [n Σxy − (Σx)(Σy)] / D  (Fraction)
MSE = Σ(y − a − bx)² / n
独立oracleはproductionをimportせず、正規方程式を有理数で解く。係数、MSE、候補選択の一致を検査する。MSEの分母nは、残差分散の推定で使うn−2とは別。
