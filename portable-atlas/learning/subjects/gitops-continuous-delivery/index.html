3 原典／実装 → 答え
OpenGitOps v1.0.0の4原則から宣言とreconcileの関係を読む。実runnerはfile bytesとhashを照合し、最新generationだけ適用。独立遷移table／state hash oracleと入力manifestを比較。
driftとrollbackの答え
applyは手動driftをdesiredへ戻します。observe-onlyは差分が残ります。旧v1 packetはv2が最新なら拒否。rollback-v3はv1と同じbytesですが、新generationで前内容を宣言するため適用されます。ignore-noteではmanaged一致でもexact一致ではありません。
source binding ／ ArgoのSelf-Healing／Sync Semantics ／ Respect Ignore Differences。模型のignoreは比較と適用の両方を除外する独自仕様です。
