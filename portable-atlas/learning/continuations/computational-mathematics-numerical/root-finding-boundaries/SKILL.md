# 反復求根の停止理由を読む

まず [README](README.md) と [前提](PREREQUISITES.md) を確認する。説明だけで求根・ブラウザー・外部要求を起動しない。任意式の解や一般の収束を保証しない。

- 「0と1を行き来して止まった」なら `cubic-cycle`。更新4回、返却0、残差2を読み、循環専用停止ではなく更新上限であると説明する。同式の `cubic-local` を比較し、初期値だけの違いを確認する。
- 「幅が小さいのに残差が大きい」なら二分法 `cubic-cycle` のk=4。保持区間[-15/8,−7/4]、中点−29/16、幅1/8、半幅1/16と残差1349/4096を分ける。半幅は条件付きの距離上界で実測誤差ではない。
- 「残差だけ小さければ止まるか」なら `bad-bracket` のNewton k=2→3。k=2は残差1/144だがstep1/12、k=3は残差1/166464かつstep1/408。今回のAND条件を示し、一般の根誤差保証に広げない。
- 「導関数0なら必ず失敗か」なら `zero-derivative` と `exact-endpoint`。前者はf非零で更新0の停止、後者はf=0が先で厳密根。stepはどちらもnullで、0という測定値へ置換しない。
- 「[2,3]が拒否されたので根はないか」なら `bad-bracket` の二分法検証欄。端点値2と7の同符号による開始拒否で、一般の根不存在判定ではない。Newtonは区間を引数に取らず初期1から更新する。
- 「実装に使いたい」なら [SOURCES](SOURCES.md) と [CONTRACT](CONTRACT.md) に戻る。本番の停止判定は関数・尺度・許容誤差・数値表現に応じた検証が必要。本教材は5条件の厳密分数、速度・浮動誤差・ライブラリ互換は未検証であると説明する。

保存結果の欠落・改変・別条件では、画面の古い答えを根拠にしない。実際に保存された停止理由と未到達nullを読み、必要な証拠が無ければ未確認として止める。
