# Atlas：反復求根：何を根拠に止めたのか

同じ方程式でも、初期値や区間によって返る値と停止理由が変わります。二分法の「根を含む区間が狭くなった」とNewton法の「残差と更新幅が小さくなった」を、5条件の保存された列で読み比べます。

1. [前提](PREREQUISITES.md)で分数、導関数、残差と誤差の違いを確認します。
2. [画面](index.html)で停止理由を予想し、保存結果を開き、前後の境界を比較します。
3. [契約](CONTRACT.md)・[手計算](HAND-CALCULATION.md)と[計算の実装](model.py)を照合します。
4. 答えを開き、[原典と独自規約](SOURCES.md)へ戻ります。[Skill](SKILL.md)は問いに応じて読む条件を案内します。

## 比較する問い

|条件|読む判断|
|---|---|
|同式・初期0|0と1の往復は更新上限で止まる。返却値0は根ではない|
|同式・初期−2|同じ4回の予算でも2回で局所しきい値を満たす|
|導関数0|fが非零なら除算できない。根の有無全体は判定していない|
|不適切な区間|二分法の開始拒否を、区間を使わないNewton法へ転用しない|
|最初から根|f=0の判定を先に行い、導関数0でも更新0で終わる|

二分法の返却候補は**現在保持している区間の中点**です。その区間を選んだ直前のprobeとは別です。連続な固定多項式で根を含む区間を維持したとき、その中点から区間内の根までの距離は半幅以下です。表示残差はこの半幅とは異なる量です。

Newton法は更新後の残差と更新幅を同時に調べます。`bad-bracket` のNewton k=2では残差だけ合格し、まだ止まりません。両方合格も一般の根との誤差保証ではありません。
