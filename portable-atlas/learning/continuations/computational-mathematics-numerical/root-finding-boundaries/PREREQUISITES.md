# 前提から読む順

共有教材は読取り専用です。下の相対リンクはファイルとしての実在を確認した導線です。この単元だけを配信するHTTPサーバーの範囲外なので、同じ画面で開けた証拠とは扱いません。



分数・絶対値・関数と導関数を確認し、残差が小さいことと解に近いことを区別してから進みます。二次式の別計算経路は浮動小数の問題を扱う前提で、今回の厳密分数の反復とは分けます。

本単元は [契約](CONTRACT.md) → [手計算](HAND-CALCULATION.md) → 保存された反復列の対照 → [原典](SOURCES.md) の順で読みます。再利用した旧単元を今回の新規成果に数えません。
