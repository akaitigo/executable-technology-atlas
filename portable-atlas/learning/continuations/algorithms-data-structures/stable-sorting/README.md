# Atlas｜同じ値の順番は、整列した後も残る？

[学習画面](index.html)では、keyの順、要素を失っていないか、同じkeyの元順という3つの問いを分けます。混在重複 `[2A,1B,2C,1D,2E]` は、安定な2方式では `B,D,A,C,E`、同値を右から取る併合では `D,B,E,C,A` と予想します。後者もkey順は正しいため、それだけで成功とは判断できません。

## 読む順
1. [既存lower-bound](related.html?topic=lower-bound)で整列済みという前提を確認し、[有限契約](CONTRACT.md)で比較と配置の数え方を読む。
2. 条件と予想を選び、保存した計算結果を表示する。カードのID順と3判定を比べ、途中の列を追う。
3. 検索欄で、整列を一度行う比較と各検索の比較を分ける。配置回数は別の費用として読む。
4. [原典](SOURCES.md)と画面の実行時コードを確認してから答え合わせする。
5. 安定性が必要か、短い検索列で準備費用を回収できるか、実時間を別途測る必要があるかを説明する。

画面は保存したPython計算を読むためのものです。操作でPythonを再実行したり、Python組込みsortを評価したりしません。図は計算結果から作る説明図で、実画面写真ではありません。
