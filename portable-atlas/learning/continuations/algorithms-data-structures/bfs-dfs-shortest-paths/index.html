3 · 正常な探索と、解釈の誤りを比べる
DFSは誤ったalgorithmではありません。「最初に発見した経路を最短と呼ぶ」判断が、反例で崩れます。自己loop/cycleで再訪しないことと、最短性は別です。
答え：何を最小にしている？
ここで最短は辺数の最小。BFSはenqueueと同時にvisited/parentを固定し、同じ頂点を重複投入しません。queueの距離層を保つので最初の発見が最短です。dequeueまで印を遅らせると、別の親から同じ未処理頂点を投入でき、この一回投入契約を失います。
DFSは未訪問の隣へ深く進み、戻って別枝へ進む探索。first parentの経路は有効でも最短とは限りません。同距離経路ではBFSも唯一解ではなく、隣接順が選択を決めます。
無重みの最小hopはBFSを検討。到達性や深い探索にはDFSが選択肢。重み付き経路・最適化全般へこの結果を転用しません。
