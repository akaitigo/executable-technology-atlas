# Atlas：複数語の寄与と原典への対応

- 分野目標67と、前教材 `../search-term-frequency-length/COVERAGE.md:16` の未対応範囲を引き継ぎます。以前は1語のIDFが候補すべてに共通していました。今回は語ごとの文書頻度と寄与の和を扱います。
- 著者原典 [Okapi BM25: a non-binary model](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html) の式86を使用します。今回の正式Web読取では、本文13–16行の語ごとの和と頻度・長さの係数、8–11行の別IDF式85、17–20行の検索語頻度を加える式87を照合しました。本文の生バイトやハッシュを取得したとは主張しません。
- IDFの自然対数、k1=1、b=0、4文書・検索語alpha/beta、重複排除・辞書順・未知語拒否・同点時ID順は教材の固定条件です。特定の検索製品の既定動作を説明するものではありません。
- 同じ文字列を何回問い合わせても重みを増やさないのは今回の規約です。式87や語句検索との違いを残します。前教材・共有元・既存受入記録は変更しません。

実装前に入力と手計算を固定し、別担当が本文から数えた文書頻度、有理数の積による順位、候補集合を照合します。計算結果を得るまでは実行済みとは説明しません。
