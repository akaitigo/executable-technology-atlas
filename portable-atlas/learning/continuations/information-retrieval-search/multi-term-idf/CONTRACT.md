# Atlas：検索語ごとの重みを足す実装前契約

分野目標67、前教材 `search-term-frequency-length/COVERAGE.md:16` の複数語と異なる文書頻度に対応します。語の回数と文書長を固定し、IDF（少ない文書に現れる語へ大きい重みを付ける今回の式）の寄与に絞ります。検索品質や実検索製品の動作は測りません。

## 固定入力と式

4文書はすべて空白区切り4語です。d1=`alpha x x x`、d2=`beta x x x`、d3=`alpha beta x x`、d4=`alpha x x x`。検索語の文書内回数は0か1です。入力順d4,d2,d3,d1と、同点時のID昇順を区別します。N=4、平均長4、文書頻度はalphaが3、betaが2です。xは本文の語ですが今回の検索語には選びません。

著者原典のBM25式86を、k1=1、b=0、自然対数IDF=`ln(N/df)`に固定します。1回一致した語の頻度係数は `(1+1)*1/(1+1)=1`。したがって得点は、一致した検索語のIDFを足したものです。比較用に、同じ一致語へすべて重み1を付けた得点も保存します。この対照だけをBM25の製品既定式とは呼びません。

式85の確率的IDFや `ln(1+...)` は使いません。式87の検索語の反復回数による補正も使いません。語の回数・長さによる補正を今回の変化原因と説明しません。

## 検索語の規約

- 入力は小文字ASCIIの1〜3語を単一空白で区切った文字列です。本文を変える操作はありません。
- alpha、beta、alpha beta、beta alpha、alpha alpha betaの5条件を保存します。検索語は重複を除き辞書順にそろえるため、後半3条件は同じ得点・候補・表示順です。これはこの教材の規約で、一般的な検索製品の仕様ではありません。
- 候補は、指定語の少なくとも1つを含む文書です。両語を必須とする検索や語順を指定する検索は対象外です。
- 本文に存在しないgammaを含む `alpha gamma` は全体を入力拒否にします。既知のalphaだけへ黙って縮めず、df=0の対数は計算せず、得点も返しません。
- 同点はID昇順で表示します。非一致は説明表に得点0で残し、候補にも表示順位にも入れません。語順と反復を変えた条件でも、要求した入力の識別子は保持し、別条件の古い記録を流用しません。

## 独立した手計算

I_alpha=`ln(4/3)`、I_beta=`ln2`と置きます。alphaだけならd1,d3,d4がI_alphaで同点、betaだけならd2,d3がI_betaで同点です。両語ならd1=I_alpha、d2=I_beta、d3=I_alpha+I_beta、d4=I_alphaで、d3→d2→d1→d4。同点d1/d4は得点差ではありません。BM25の長さ補正を表すbとは別の記号です。

別の照合として、得点を指数関数で戻した値を有理数で固定します。両語なら4/3、2、8/3、4/3で、正の増加関数による変換なので同じ順位になります。非一致の指数変換は1ですが、得点が1なのではなく0であり候補外です。計算側はmath.logによる浮動小数点計算、検査側は固定有理数の積とDecimal.lnで求める独立期待へ絶対差1e-12で照合し、数え方・候補・順位・同点は完全一致とします。

手表は計算実装より先に保存します。手表の値だけを計算済みの画面へ入れません。実行後の標準出力から画面用データを作り、語ごとの回数・df・IDF・寄与、寄与和、重み1の対照、候補・同点・表示順を照合します。
