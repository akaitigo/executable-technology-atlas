# Atlas：検索語ごとの重みを足す

同じ1回の一致でも、語が何件の文書に現れるかによって寄与が変わります。4文書の長さを4語、各検索語の回数を0か1にそろえ、alphaとbetaの文書頻度、語ごとのIDF、合計得点を比較する教材です。

入口は [index.html](index.html) です。固定入力の計算を保存し、学習画面へ接続しました。幅1280/390の実画面操作と画像保存を実施しました。確認範囲と最終独立受入の状況は [画面確認](GUI-QA.md) にまとめています。

## 前提と読む順番

文書ID、語の回数、一致集合、足し算を使います。前の [語の頻度と文書長](../search-term-frequency-length/index.html) では1語のIDFが共通でした。今回は語ごとに文書頻度が違うことが新しい焦点です。

- tfは文書内の語の回数、dfはその語を含む文書の数です。今回alphaは3文書、betaは2文書に現れます。
- Nは全4文書。今回のIDFは自然対数 `ln(N/df)` です。alphaは `ln(4/3)`、betaは `ln2` なのでbetaの方が大きくなります。
- 一致した語の寄与を足します。どの語にも重み1を付けた対照も並べ、語の重みで何が変わったかを分けます。

予想→入力を選ぶ→保存計算の比較→原典・実装→答え合わせ→限界の順で読みます。対数の計算に慣れていなくても、画面の語別寄与と合計から始められます。

| 入力 | IDFを使う手計算の順位 | ポイント |
|---|---|---|
| alpha | d1=d3=d4。d2は候補外 | 同じ1回の同じ語なら同点 |
| beta | d2=d3。d1/d4は候補外 | alphaより大きい語の重み |
| alpha beta | d3 > d2 > d1=d4 | d3は両方の寄与を足す |
| beta alpha | alpha betaと同じ | 辞書順にそろえる独自規約 |
| alpha alpha beta | alpha betaと同じ | 反復を除く独自規約 |
| alpha gamma | 入力全体を拒否 | alphaだけへ縮めず、得点なし |

両語を使った重み1の対照では、d3の得点は2、d1/d2/d4は1で同点です。IDFを使うと、この同点のうちd2が高くなります。回数や長さを変えた効果ではありません。同点内のID順は表示規約で、優劣ではありません。

## 原典と計算の対応

[著者原典のBM25式86](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html)をk1=1、b=0に固定します。一致した語は1回なので頻度係数は1です。式85の別IDF、ln(1+...)、検索語の反復回数を加える式87には置き換えません。入力の規約は製品共通の仕様ではありません。

[契約](CONTRACT.md)、[固定入力](fixtures.json)、[実装前の手計算](hand-oracle.json)を先に保存しました。本文から数えた値と順位を別担当が独立に確認してから、[計算処理](model.py)と[保存結果の照合](verify.py)を実装しています。

詳しい照合では、合計得点を指数関数で戻した正の有理数を使います。両語のd1/d2/d3/d4は4/3、2、8/3、4/3。順序を保つ変換なので、整数の比だけでも順位を証明できます。得点自体は浮動小数点による計算と、固定有理数からDecimal.lnで求めた独立期待を絶対差1e-12で照合します。これは一般的な検索の正しさの証明ではありません。
