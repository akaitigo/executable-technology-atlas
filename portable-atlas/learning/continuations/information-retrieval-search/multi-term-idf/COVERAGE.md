# Atlas：複数語の検索で扱う範囲

分野目標67と、前教材の異なるdf/IDFという不足に対応します。TF・長さ・Boolean一致・precision/recallそのものを新しい学習済み概念として再加算しません。

| 新しい問い | 有限な対照 | 境界 |
|---|---|---|
| 同じ1回でも寄与は同じか | df alpha3/beta2、重み1とIDFを対照 | TF1/文書長4を固定 |
| 複数語はどう合計するか | d3のalphaとbetaを別に表示して足す | 特定の2語だけ |
| 語順や反復はどう扱うか | 元入力を保持し、正規化後の同一結果を比較 | 今回の重複排除規約だけ |
| 未知語を混ぜるとどうなるか | alpha gammaを全体拒否、得点なし | 既知語だけへ縮める製品もあり得る |
| 同点と表示順を区別できるか | IDFありd1/d4、対照d1/d2/d4の同点 | ID順は独自の表示規約 |
| 検査を計算から分けられるか | 固定有理数の積、Decimal.ln、候補と順位の独立照合 | 一般検索エンジンの検証ではない |

実装前の契約・独立期待を固定した後、5成功入力・20文書・32語寄与、未知語1入力の全体拒否、その他13入力の拒否を保存しました。[保存値の照合](observations/calculation-verification.json) は全値と12種類の改変検出を確認しています。高負荷で起動しなかった3回の記録も保持しています。

画面へ渡す値は保存計算と対応し、純粋な状態処理69項目を隔離された JavaScript 環境で確認しました。実DOM・実操作・1280/390幅の画像は、再利用したブラウザーで別に記録しました。範囲と制限は [画面確認](GUI-QA.md) を参照してください。CLI の独立確認と、教材全体の最終受入を分けて扱います。

次の不足は、順位に対して固定した関連性の正解ラベルを用いた評価です。既存precision/recallとの対応を確認してから選び、今回のIDF寄与を検索品質の改善へ読み替えません。語句検索、検索語頻度の補正、他のIDF形式、製品比較、性能は別の問いとして残します。

共有元と旧教材は読取専用です。全体台帳や共有計画の更新、教材数の加算は担当しません。
