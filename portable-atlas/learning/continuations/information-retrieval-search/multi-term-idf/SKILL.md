# Atlas：語ごとの寄与を読む案内

最初にREADMEとstatus.jsonの実施状況を読み、計算が未実行なら手計算の予想と区別する。この教材の固定入力・保存結果だけを扱い、実際の検索エンジンや他製品の規約へ広げない。

1. tfは文書内の回数、dfはその語を含む文書の数と説明する。4文書の長さ4と、検索語の回数0/1を先に確認する。
2. 元の検索入力を読む。語順をそろえ反復を除いた後の語と混同せず、入力変更後の古い結果を使わない。
3. 予想→保存結果→語別寄与→2種類の合計と表示順→原典・手計算→答えの順へ案内する。
4. 未知語による計算全体の拒否と、保存記録の欠落・改変・別入力による読取拒否を分ける。拒否時には以前の成功表を答えとして使わない。
5. 語の重みは順位の計算規則であり、利用者の関連性や品質の評価は別の証拠を要すると説明する。

## 独立に確かめる3つの案内

- 「両語検索で、d1とd2は同じ1回なのになぜd2が先？」：alphaのdf3、betaのdf2、同じN4からIDFの違いを示す。重み1では同点で、TFや長さが変わった説明をしない。
- 「beta alphaやalpha alpha betaでも同じ？」：元入力と重複排除・辞書順の結果を示す。今回の規約で同一になったと説明し、式87や語句検索も同じとは断定しない。
- 「alpha gammaならalphaだけで探してくれる？」：今回の保存結果では未知語を含む入力全体を拒否し、得点を返さないことを確認する。記録の読取エラーとは別に案内する。

新しい計算やブラウザーは勝手に起動しない。通常の利用にインストール・新サービス・設定変更は不要。3例の有限な案内確認を、一般の案内役の能力保証とはしない。

画面の案内では [Atlas の画面確認記録](GUI-QA.md) を参照し、実際に確認した条件と残る制限を伝える。過去の計算結果を、新たに計測した結果として扱わない。
