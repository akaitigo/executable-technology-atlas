# Atlas：検索順位の実装前契約

対象は4文書・検索語alphaの保存計算教材です。検索engine、実利用者の評価、検索品質の改善を実証しません。既存Boolean検索とprecision/recallの教材を前提に、「何が一致するか」と「どの順に並べるか」を分けます。

## 固定する式と意味

- Nは空文書を含む文書数4。dfはalphaを1回以上含む文書数2。tfは各文書での出現回数です。
- 文書長dlは空白で分けたtoken数。avgdlは全16 token / 全4文書 = 4。空文書も分母の文書数に含めます。
- IDFは自然対数 `ln(N/df) = ln(2)`。全候補で共通かつ正です。
- 比較するTF×IDFは `tf * ln(N/df)`。tfの対数化、文書長やベクトル長での正規化をしない基準です。すべてのTF-IDF方式を代表しません。
- BM25は著者原典の式86を検索語1つへ限定した `ln(N/df) * ((k1+1)*tf)/(k1*(1-b+b*dl/avgdl)+tf)`。k1=1、b=0・1/2・1だけを比較します。
- 原典式85の `ln((N-df+0.5)/(df+0.5))` や `ln(1+...)` は使いません。今回N4/df2なら式85は0になりますが、その式を代入して順位説明を流用しません。負のIDFの処理も対象外です。
- tf=0は非一致です。検索候補から除き、説明用の表には得点0・順位なしを残します。空文書でb=1の場合も除算前にこの分岐へ入り、0/0を計算しません。
- 同点は文書IDの昇順で表示します。これは教材の独自規約です。入力順はd2,d1,d4,d3として、入力順の保持と区別します。「表示順位」と「同点群」を別に記録します。

## 入力と前提

fixtures.jsonの4文書と4方式だけを学習UIに出します。本文は小文字ASCIIの語を単一の空白で区切ったもの、または空文字列。大小文字変換、句読点、日本語解析、stemming、semantic検索は行いません。前提は集合、割合、分子と分母、語の回数です。対数を知らなくても、共通の正の係数ln2を外した表で順位を比較できます。

空文書を1件含めますが、全文書が空、検索語が空、df=0の入力では計算を始めず入力エラーにします。N=4、IDはd1..d4の重複なし、各文書0..8 token、検索語は小文字ASCIIの1語を上限契約にします。boolや余分なkeyを数値や設定へ黙って変換しません。任意SQLや外部path、製品engineへ入力を送る機能はありません。

## 予想と独立照合

実装前にhand-oracle.jsonの16行を固定します。各行のtf・dl・検索語位置は手で数えました。共通IDFを外したd1/d2の係数は、基準2/1対1/1、b0は4/3対1/1、b1/2は8/7対8/7、b1は1/1対4/3です。非一致d3/d4はすべて0・候補外です。

producerは標準mathの浮動小数計算を行い、整数の回数・分子・分母・係数・最終得点を保存します。独立検査は固定手表とFractionによる有理数を使い、producerをimportしません。有限4方式の同点は同じ値になり、ID昇順を保存します。数値比較の絶対許容差は1e-12、ID集合・順位・同点群・未計算分岐は完全一致とします。一般の浮動小数同点判定法を保証しません。

記録欠落、別方式の結果混入、順位やN/df/avgdlの改変を検出し、以前の正常結果を現在の答えとして残さないreaderにします。原典→式→手計算→Pythonの計算結果→表示値の対応を独立担当が確認します。

## 実行と資源

既存Python標準ライブラリのみ。実計算前にrootへ連絡して単独枠を確保し、CPU/load・メモリー・競合を読みます。子自身のnice10設定と実値確認が成功したときだけ計算へ進みます。設定失敗は準備失敗で、期待入力拒否や計算成功とは分けます。

本計算は1子・観測5秒以内、回収猶予2秒別、完全stdout/stderr・source/input hash・終了を保存。未回収なら後続操作を始めません。成功値を得るための再試行はしません。ブラウザーは別の専有枠で保存結果だけを読み、WASI/検索engineや新サービスは起動しません。

## 実務判断と限界

回数が多い文書を常に先にしたいのか、長さを補正したいのかを式と目的から説明します。今回の逆転を「BM25が必ず優れる」「短文ほど関連が高い」と読み替えません。k1/bの最適化、関連性label、precision@k、複数語、製品互換、性能、大規模index、incremental更新は未評価です。
