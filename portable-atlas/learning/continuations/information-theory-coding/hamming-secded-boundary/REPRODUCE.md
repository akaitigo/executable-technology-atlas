# Atlas｜SECDEDの計算を再現する

Python 3標準ライブラリで動きます。SDKやパッケージの追加は不要です。実行場所はこの教材のディレクトリです。

## 教材を開く

```sh
python3 -B serve.py
```

[http://127.0.0.1:18755/](http://127.0.0.1:18755/) を開きます。自分のPCのloopbackだけに配信し、終了はCtrl+Cです。ポートを変える場合は `--port 18756` を付け、表示されたURLを使います。既存の別サービスを停止しないでください。

画面は保存した計算結果を選ぶreaderです。ブラウザー操作のたびにPythonの復号器を実行するものではありません。外部の原典リンクを自分で開いた時だけ、そのサイトへ接続します。

## 計算と照合

```sh
python3 -B run.py
python3 -B verify.py --record observations/run-01
```

最初のコマンドは有限な計算を行い、件数を表示します。2つ目は既存の計算結果を読み、実装とは別の全符号語距離方式で照合します。保存した記録は上書きしません。

新しい結果を残す場合だけ、まだ存在しない名前を指定します。

```sh
python3 -B run.py --record observations/my-run-01
python3 -B verify.py --record observations/my-run-01
```

`run-01` とその入力snapshotは既存の証拠なので変更しません。新しい実行をしただけでは、readerの読込先は切り替わりません。

送信列を作る処理と、受信列だけから判断する復号器を分けています。元の情報・反転位置は実験側だけが持ち、`answerCheck` の答え合わせに使います。拒否した場合、訂正後の列と復号した情報は `null` です。

## 画面の確認

`check_gui.py` は、このPCに既にあるPlaywright/Chromiumを使う開発用確認です。専用profile・sandbox有効・nice 10で1ブラウザーを起動し、終了時に自分のprofileとserverを片付けます。別担当と実行時間を調整してから使い、ブラウザーの追加インストールは行いません。計算結果や期待表を書き換えず、503・内容不一致・古い応答はブラウザーへの応答だけを差し替えて確認します。

2026-10-06の保存確認は21項目、実ポインター72回・キー操作8回、幅1280/390の画像15枚です。nice 10で約3.34秒の1回の確認を行い、browser・専用profile・serverの終了を記録しました。保存計算と画面実装6ファイルは確認前後で同一です。遅延応答の確認はAbortを含む通常の読込経路で行い、世代番号だけを単独で強制する試験ではありません。

実通信やハードウェアの検証はありません。画面確認の記録は `qa/run-2026-10-06T075745508Z/report.json`、別担当の受入の参照先は `qa/reader-acceptance.json` です。
