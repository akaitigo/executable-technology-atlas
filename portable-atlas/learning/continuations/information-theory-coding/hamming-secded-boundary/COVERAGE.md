# Atlas｜SECDED教材が扱う範囲

分野目標05「情報理論・符号化」のうち、全体偶数パリティを足したSECDED（1ビット訂正・2ビット検出）の判定境界を扱います。



| 内容 | この教材の根拠 | 到達範囲 |
| --- | --- | --- |
| 位置規約・偶数パリティ・s/qの4分岐 | 手書き予想、実装、全条件計算 | 固定8bit構成 |
| 位置1〜7の単一訂正と位置8の訂正 | 16メッセージ×8反転 | 128条件 |
| 二重誤りを任意候補へ訂正しない | 448条件＋独立距離照合 | 全二重反転 |
| Hamming(7,4)との比較 | 464条件 | 既存主題を対照として再利用 |
| 検査通過と無誤りの違い | 3bit・4bitの反例 | 各1例。全多重誤りではない |
| 保存計算の読込・予想・比較・答え | 日本語reader、実操作21確認、実画像15枚 | 幅1280/390、失敗・回復・古い応答を含む |
| 実通信・機器のECC | 未実施 | 模型を実機測定と扱わない |

計算は1056条件＋保証外2例。作者による別方式照合11,786項目、別担当の独立照合13,779関係が一致しました。期待表は計算前の履歴として不変に保ちます。readerは72回の実ポインター操作と8回のキー操作を確認しました。15画像は実際のChromium画面であり、機器の測定画面ではありません。別担当の最終受入は [参照記録](qa/reader-acceptance.json) に分けて残します。

この単元の後に残るのは、誤り率と通信路モデル、バーストへの対処、符号の長さと冗長度、畳み込み符号・LDPC等、圧縮との目的の違い、実装・機器固有の境界です。分野目標05全体の完了を意味しません。
