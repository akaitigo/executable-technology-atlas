# Atlas：先に知ることと既存の実例

この教材だけをHTTP配信しても、この説明・固定入力・手表・原典対応・実装・Skillへ進める。元教材は配信範囲外なので、下の場所は参照元の識別情報であり、ブラウザーで開けた証拠ではない。元ファイルのhashと保存結果の場所は [sources.json](sources.json) にまとめる。

1. **状態と順序**：状態が操作で変わること、有向辺に沿う経路、全ての組を並べられる全順序と、並べられない組もある部分順序を確認する。
2. **既存の分散入口**：Lamport型counterはlocal writeで増え、receiveで `max(local, incoming)+1` になる。版をcounterとreplica IDで比べると勝者を選べる。ただし勝者の選択は「因果的に後」を判定することではない。保存された固定3メッセージの全6配送順では版のmaxが一致する。
3. **既存のEdge入口**：2成分のversion vectorは、全成分以上かつ1成分以上で大きい版を後継として扱う。A1=[1,0]をA2=[2,0]が置き換え、独立のB1=[0,1]はA2と比較不能なので両方のheadを残す。受信後にBが書いた[1,1]はA1の後継になる。これは保存40配送例の範囲であり、今回vector算法を作り直さない。
4. **今回の問い**：版の比較から一段戻り、どのイベント対に実際の経路があるかを全15組で確かめる。[手表](HAND_TRACE.md)の予想後、[画面](index.html)で条件を選ぶ。
