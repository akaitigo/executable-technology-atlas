# Atlas：実装前に手で辿る15組

これは測定結果ではなく、入力から先に決めた予想である。Pはa→b→c、Qはd→e→f、メッセージはa→eとf→c。

| 左 | 右 | 手で辿った関係 | 経路の例 |
|---|---|---|---|
| a | b | 左が先 | a→b |
| a | c | 左が先 | a→b→c |
| a | d | 並行 | 両方向に経路なし |
| a | e | 左が先 | a→e |
| a | f | 左が先 | a→e→f |
| b | c | 左が先 | b→c |
| b | d | 並行 | 両方向に経路なし |
| b | e | 並行 | 両方向に経路なし |
| b | f | 並行 | 両方向に経路なし |
| c | d | 右が先 | d→e→f→c |
| c | e | 右が先 | e→f→c |
| c | f | 右が先 | f→c |
| d | e | 左が先 | d→e |
| d | f | 左が先 | d→e→f |
| e | f | 左が先 | e→f |

方向のある因果関係11組、並行4組。経路が複数ある組では、実装がこの例と別の合法な経路を保存してもよい。各経路の辺は固定6本のいずれかである必要がある。

時計はa1/b2/c4/d1/e2/f3。因果11組はすべて時計が増える。しかしd1<b2でもdからbへ行けず、b2<f3でもbからfへ行けない。逆推論の13組にはこの2組の誤りがある。同値のa/d、b/eを同じ物理時刻とは呼ばない。

R1=a,b,d,e,f,c と R2=d,a,e,f,b,c はどちらも合法である。R2の表示でf3の後にb2が来ても矛盾ではない。互いに並行な別プロセスのイベントを、表示用に並べているだけである。

R1の表示位置を因果の辺と誤認すると全15組がつながり、並行だった4組にa→d、b→d、b→e、b→fを作ってしまう。この向きはR1に固定する。任意の並べ替えで同じ向きになるとは主張しない。
