# Atlas：実装前の手追跡

1. `0` は最初から値。budget0でも遷移0、value0。
2. `(1+2)+(3+4)` → `3+(3+4)` → `3+7` → `10`。根からの規則列は AddLeft/AddInts、AddRight/AddInts、AddInts。計3遷移、4状態。
3. 同じ列を2遷移だけ適用すると `3+7`。値ではなくAddIntsが適用可能だが残予算0なので停止。次項10はこの列では未実行。
4. `(fn x → x+1)(2+3)` → `(fn x → x+1)(5)` → `5+1` → `6`。CallArg/AddInts、Beta、AddInts。関数本体x+1を先に計算しない。
5. `0(1+2)` は値でも適用可能規則を持つ項でもない。旧Atlasと合わせて引数前に止まり、stuck。引数1+2が3へ進んだ証拠を作らない。

期待JSONに各状態の全ASTを保存する。既存big-stepは順に0/10/10/6/not-callableを返すと手導出した。再帰呼出しのenter/returnログを小ステップの列へ読み替えない。型checker・一般置換・全入力の停止性/同値性はこの手表から導かない。
