04 / 答え合わせ
「拒否した」で、確認を終えない
拒否時はstore全体、許可時は対象recordの指定fieldだけを確認します。この教材のメモリ内置換は、実DBのtransaction・並行競合・プロセス停止後の回復を検証していません。
要求ごとに初期化した24条件です。連続サービスの回復試験、JWT・認証、分散制御、JSON重複キーやnested値は別の不足として残ります。
