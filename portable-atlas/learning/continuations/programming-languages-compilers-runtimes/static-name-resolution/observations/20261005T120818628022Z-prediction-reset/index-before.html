1. 規則と予想

useは、内側から探して見つかる「先に現れた同名宣言」に束縛します。内側letより前なら外側x=10、内側let以降ならx=20、blockを出ると外側10。未宣言・scope外の名前は全評価開始前に拒否します。

この独自の逐次宣言契約を検証します。JavaScript letのTDZ、closure、型検査、任意ソース実行は対象外です。
