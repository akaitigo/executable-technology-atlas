# Atlas：実装より先に決めた手計算

stackの左が底、右が頂点です。以下は測定結果ではありません。完全な固定値は [expected.json](expected.json) へ。

`2 + 3 * 4` は `[] → [2] → [2,3] → [2,3,4] → [2,12] → [14]`。乗算nodeが先に完了し、加算nodeへ12が渡ります。

`(2 + 3) * 4` は `[] → [2] → [2,3] → [5] → [5,4] → [20]`。Group自体の命令はなく、括弧がASTの親子関係を変えたことが命令順に表れます。

`2 + 2 * 2` は定数表 `[2]` のindex0を3回loadします。定数の数1、CONST命令の数3、生成したstack値の個数を区別します。

Atlasの拒否は、負indexをPythonの末尾参照へ流さない、二項演算のpop前に要素数を確かめる、終了時に1要素だけであることを確かめる、という別々の段階です。値0の正常終了と、拒否による値なしは異なります。
