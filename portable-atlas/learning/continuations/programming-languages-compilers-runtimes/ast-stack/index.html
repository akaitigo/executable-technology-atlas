5　限界と実務での判断
今回の命令は JSON の配列で、バイトコードの符号化や機械語ではありません。木評価器は命令列を読まず、VM は AST を読みません。ただし共通の Python や入力まで独立しているわけではありません。加算と乗算は左右を入れ替えても値が同じなので、値だけでなく出所・命令順・各 stack を確認します。
文字列の解析拒否、任意 AST、変数・関数・型検査、制御の分岐、最適化、機械整数の桁あふれ、性能、GC 連携は今回の新しい実測範囲外です。不正命令の拒否は VM の境界であり、資料の読込み失敗や Python 実行失敗とは区別します。
