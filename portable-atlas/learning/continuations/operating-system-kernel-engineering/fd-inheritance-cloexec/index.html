5. 実務で使う判断と限界
子へ渡す FD を意図的に選び、exec の前に各 FD の印を確認します。複製を作っただけでは、片方の印がもう片方へ一括反映されると考えません。子の終了を回収し、親側の参照も明示的に閉じます。
同じ番号が別ファイルへ再利用されることがあります。今回の測定は dev / ino を照合し、違う対象なら成功にしません。同じファイルの識別値だけで、offset を持つ「開いた参照」全体の共有を実証したとも言えません。
この Mac・Python 3.9.6 の 4 条件です。offset 共有、マルチスレッドからの fork、FD の race、全 OS、性能、メモリーや耐久性は未検証です。
