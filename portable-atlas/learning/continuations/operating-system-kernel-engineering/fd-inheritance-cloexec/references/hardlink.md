# Atlas：同じ内容、同じファイル？

[教材画面を開く](index.html)。hardlink（同じファイル実体を指す別名）と、内容を新しいファイルへコピーする操作を比べます。Mac 標準 Python の所有一時ディレクトリに、最大 3 つの名前・2 つの実体・各 6 バイトだけを用意しました。

この単元で分かることは次の 6 項目です。

1. 内容が同じでも、同じファイル実体とは限らない。
2. `st_dev`（デバイス番号）と `st_ino`（inode、実体の番号）を同じ実行内で組にして比べる。
3. `nlink` は同じ実体を指す名前の数であり、コピー数ではない。
4. hardlink 経由の書換えは元の名前にも見え、今回の内容コピーへの書換えは別だった。
5. 既存の宛先への link は `EEXIST` として失敗し、前後の状態は変わらなかった。
6. 元の名前を削除しても別名から読めたことと、物理配置・耐久性の保証を分ける。
