mmap: Bはどこに見える？

AAAAのindex 1へBを書いた後、mapping・副readonly mapping・別file readを比較する。各modeは別の4-byte fileを使った実測ログ。

安全なAPI境界: 実際の拒否

拒否は書込成功と別に数える。生pointer・mapped fileのtruncate・SIGBUS誘発は実行していない。

操作offset / length実例外最終file

答えと測定の境界

WRITEはmapping・副mapping・fileがABAA。COPYは書いたmappingだけABAA、fileと副mappingはAAAA。READはTypeErrorで拒否。COPYでもflushはNoneを返したがfileはAAAAのまま。

flush成功は電源断耐久性の証明ではない。物理COWページ数・pagefault・別processでの可視性は未測定。mapping.closeとfile.closeは別操作。

pipe / FDから次へ

pipeのread/writeで見たFDと同じく、file objectには寿命がある。mmapのclose後もfile objectは開いており、mappingとFDを同じ寿命だと扱えない。
