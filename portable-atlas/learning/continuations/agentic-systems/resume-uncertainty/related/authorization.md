# Atlas — 型が正しい呼出しと、承認された呼出し

整数100を正しく取り出せても、承認されていた操作が `add(4,3)` なら、`add(100,3)` を実行してよいとは限りません。この教材では、観測を取り出す型検査と、具体的な呼出しへの承認を別の段階で読みます。

対象は、合成した計画・観測・承認を使うPythonの有限模型です。readは固定fixtureのコピー、addは純粋な和だけ。実際のLLM・API・MCP・承認画面・OS権限・外部への送信は使いません。現在の検証状況は [status.json](status.json)、画面の確認範囲は [GUI-QA.md](GUI-QA.md) に記録します。

## 前提から操作へ



1. [画面](index.html)で条件を選び、addが拒否／承認どおり実行／故障実行のどれか予想します。
2. 「保存した計算を開く」で、処理名の検査 → read → 値と型 → 承認 → addの段階図を読みます。画面で新しい計算を起動しません。
3. normalとargs-changedを比べます。後者は型が正しくても、承認された4と観測した100が違うためadd 0回です。
4. missing-grantとbad-data-approvalは入力が同じです。観測内の承認らしい値を採用する故障だけが103を返し、承認違反と表示されます。
5. [契約](CONTRACT.md)・[手計算表](hand-oracle.json)・[実装](model.py)・[原典との対応](SOURCE-MAP.md)へ戻り、答え合わせをします。

同じ計画でも承認のcall IDが違う場合、同じ引数でも計画や主体が違う場合、期限ちょうどの場合を別条件にしています。期限は論理時刻で `now < 10`。時刻10は無効です。使用済み承認も拒否します。

## 結果を読むときの注意

- 拒否9件でもreadは1回済んでいます。add 0回を「全処理が未実行」と読み替えません。文字列と旧requestは値の確認で停止し、承認照合は未到達です。
- authorized=falseは最終的に許可できなかったことを表します。個々の照合がnullなら未到達で、検査通過でも実行失敗でもありません。
- hashは固定したbyteの一致を確かめる値です。第三者の署名・ユーザーの同意・権限の存在を証明しません。承認の出所は合成入力を信頼する仮定です。
- 正常な型、正常な数値、プログラムの終了だけでは認可を守った証拠になりません。方針の故障による103を正常成功に含めません。

## このMacで読む・確かめる

Python 3.9以降の標準ライブラリだけを使用します。画面を見る場合は、このディレクトリで次を実行し、表示されたURLを使います。自分で起動した配信だけをCtrl-Cで終了します。

```sh
python3 -B serve.py --port 0
```

[serve.py](serve.py) は127.0.0.1で静的ファイルを読むだけで、計算やブラウザーを起動しません。Markdownはtext/plainで配信します。外部の前提教材への参照はローカルファイルとして辿ってください。

保存した計算の検査は `python3 -B verify.py observations/<calculationの保存先>`。実際の保存先は [実行案内](observations/README.md) に記します。検査は計算を再実行せず、固定手表・全履歴・実行時コードのhashへ照合します。新規計算の [run.py](run.py) は `--record --gate <直前の資源記録>` が必要で、[実行条件](CLI-POLICY.md) と担当間の順番を守ります。条件不成立を繰り返し試して成功値だけ残す操作はしません。

## 原典・再利用と次の判断

[OWASPのツール呼出し認可](https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html#tool-authorization-middleware)は、実行側で具体的な操作と承認を結び付ける考え方の根拠です。今回のJSON形式・期限10・逐次消費は独自の有限契約です。[Skill](SKILL.md)は、引数差替え・期限境界・観測の権限への昇格を学ぶ要求を、この比較へ案内します。

次に必要なのは、永続的な承認消費、再送や中断後の失効、実認証との接続です。本単元は並行原子性、クラッシュ耐久性、実際のAIへの攻撃耐性を保証しません。[扱う範囲](COVERAGE.md)に既存159件から差し引いた増分を示します。
