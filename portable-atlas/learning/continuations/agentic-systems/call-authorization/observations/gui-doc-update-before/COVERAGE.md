# Atlas — 呼出し認可の範囲

159件（既存127＋独立32）の受入を照合して選んだ、目標84の不足である。既存のtyped-tool-result-dataflowは型・参照を扱うが、README:59は具体的な呼出しへの承認を次課題として残す。項目別の読取／書込認可、role継承、暗号化を再制作する単元ではない。

| 到達目標 | 本単元の確認対象 |
|---|---|
| 型と権限を分ける | 型の合う100でも、承認済み4とは異なる |
| 計画と具体操作を結ぶ | actor・plan・call ID・tool・argsを個別に照合 |
| 有効期間と一回使用を読む | 論理時刻9/10、使用済み承認を比較 |
| 観測を権限に昇格しない | 同じ観測のstrict拒否と故障実行を対照 |
| 拒否の前後を読む | read済み1回とadd未実行0回、nullの未到達 |
| 既存資料へ戻る | 型付き参照→本単元→再送／pauseの残課題 |

現在は契約・手計算固定段階。実計算・画面・独立受入は未実施。進行の最新状態はstatus.jsonに記録する。分野全体の完成や全体台帳への加算を意味しない。

次の未対応は、永続的な承認消費と再送、pause中の失効、実認証・署名、並行の照合と消費である。元分野ownerの現状は未確認のため共有元へ統合しない。86の起動メモリー、89の測定遅延は今回未割当の別候補として残す。
