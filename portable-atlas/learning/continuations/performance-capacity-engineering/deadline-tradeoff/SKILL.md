# Atlas：平均と締切を一緒に確認する

この専用pathの有限教材だけで使います。LIVE、OSのスケジューラー設定、実負荷試験を行う手順ではありません。

1. index.htmlを開き、A4/B2/C1と締切A6/B3/C7を読む。締切ちょうどの完了は成功、期限後も比較用に最後まで処理する規約を説明する。
2. 短い順CBAで、FIFOより平均待ちが減るか、全員が間に合うかを予想する。
3. 比較を表示し、時刻3・6・7とAの完了7/締切6を見る。平均待ちと個別超過を分ける。
4. 締切順BACへ変え、A6/C7の等値成功を確認する。6順序の全列挙から得た結論と一般的な最適性を区別する。
5. 原典、手計算表、Python模型、保存した計算結果を読む。必要なら `python3 -B verify.py` と `node check-reader.cjs` で軽い確認を行う。通常検査は保存記録を更新しない。
6. 予想変更・リセットで古い答えが消えることを確かめる。GUIの実操作確認の有無はGUI-QA.mdを読む。

インストール、サービス起動、公開、共有台帳加算、旧教材や他作者のpathへの変更は行わない。重み、連続到着、期限後の取消しは別の課題として扱う。
