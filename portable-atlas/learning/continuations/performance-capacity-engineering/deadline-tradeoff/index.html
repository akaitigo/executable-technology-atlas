平均待ちは短い。
全員、締切に間に合う？

仕事を短い順に並べると、平均待ちは減ります。けれど、長い仕事にも締切があります。同じ3件を違う順序で処理して、平均と個別の期限を比べます。

これは固定3件の有限模型です。全員が時刻0に到着し、1台で途中中断せず処理します。tickは模型の時間で、実CPUの秒数ではありません。完了時刻が締切と同じなら間に合うとします。期限を過ぎても、比較のため最後まで処理します。

FIFOは同時到着の登録順 A → B → C。短い順は C → B → A、締切が早い順は B → A → C です。

05何を優先するか、判断する
平均待ちが小さいことと、全員が期限を守ることは別の条件です。仕事ごとの締切を確認し、平均と個別の超過を一緒に比べます。締切が早い順を選んでも、仕事量そのものが減るわけではありません。
この6順序の比較から、連続到着、周期タスク、割込みのあるEDF、一般的な最適性、実CPU性能、安全性、無期限に待つ状態を保証できません。重み・推定誤差・実測の負荷も別の課題です。
