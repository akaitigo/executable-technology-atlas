# Atlas：平均と個人の完了を一緒に読む

このファイルから `../../` が教材のルートです。日本語のREADME.mdを読み、次の有限比較を案内します。

1. 「短い順では長い仕事Aの完了がどう変わるか」を予想する。
2. `index.html` をローカルブラウザーで開く。選択メニューか「前の順序」「次の順序」で順序を選び、FIFOとBCAを同じ時刻で比べる。サーバー起動や追加インストールは不要。
3. 必要なら `python3 -B model.py --order ABC` と `python3 -B model.py --order BCA` を実行する。A5/B1/C1、到着0、1台で途中中断せず処理する前提を変えない。
4. 原典の「仕事によって必要な資源量が違う」という問いと、今回の架空の数値を分ける。手計算表を読み、平均完了6→10/3とAの完了5→7を一緒に確かめる。
5. 検証が必要なら `python3 -B checker.py` を使う。保存した計算結果、手計算、Python、JavaScriptを照合し、ファイルは更新しない。保存済みの実行日時や実行時のハッシュを、後日の文書修正に合わせて書き換えない。
6. 最後の完了7・完了3件が変わらないことを確認する。実際の処理能力、実測の応答時間分布、無期限に待つ状態をこの例から保証しない。
