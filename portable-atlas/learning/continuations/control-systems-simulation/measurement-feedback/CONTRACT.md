# Atlas — 測定値から次の状態へ進む有限契約

これは実装前の契約です。実際の機器・センサー・制御装置は動かしません。真の状態という語は模型で定義して保存する内部状態を指し、実物の真値を測れたという意味ではありません。

## 新しい問いと固定した順序

測定値を変えると、制御器が選ぶ入力と次の状態がどう変わるかを、一因子ずつ比べます。目標89と既存制御学習経路の実験3に対応し、数値解法・PIの積分と飽和・停止距離・測定統計の再制作はしません。

架空のスカラー離散模型を `x[k+1]=(x[k]+u[k])/2`、比例制御を `u[k]=1-m[k]` と定義します。目標r=1、gain=1、x[0]=0。x・m・u・rは同じ架空の無次元単位、kは標本の番号です。1 sampleを1つの仮想時間単位とし、秒や実機の周期に読み替えません。係数1/2は固定です。一次遅れの入力保持区間で exp(-h/τ)=1/2 と置いた更新と数学的には一致しますが、h/τの同定や指数関数の計測はしません。Euler近似を使わず、数値刻み比較も今回に含めません。

各kで、①参照する状態の番号と値を選ぶ → ②その測定経路だけへ固定雑音を加える → ③必要なら量子化 → ④測定mから入力uを求める → ⑤uを使って次のxを更新、の順です。状態xを測定mで上書きしません。雑音をplantの外乱として加える模型とも区別します。

## 4条件と初期履歴

| ID | 状態の参照 | 測定に加える雑音 | 量子化 |
|---|---|---|---|
| current-exact | x[k] | 0 | なし |
| delayed-one | x[k−1]、初期履歴x[−1]=0 | 0 | なし |
| fixed-noise | x[k] | k=0..6で 1/4,−1/4,1/4,−1/4,1/4,−1/4,1/4 | なし |
| quantized-unit | x[k] | 0 | 単位1の最寄り整数 |

遅延を、現在値を更新した後の値で埋めません。固定雑音は手書きの有限列で、乱数・実測雑音・独立標本・分布や平均の推定を意味しません。実際に適用する6区間の雑音は和0ですが、それを一般的な不偏性の証明としません。遅延と雑音と量子化を同時に有効にはしません。

量子化は `Q(z)=sign(z) floor(abs(z)+1/2)`、Q(0)=0です。ちょうど半分は0から遠い整数へ丸めます。+1/2→1、−1/2→−1であり、偶数丸めとは異なります。正負の半分・その直前/直後・0を独立の手表へ固定します。製品の全数値型や実ADCの振舞いの保証ではありません。

## 境界と保存する値

各条件は6更新、k=0..6の7境界、合計28境界です。k=0..5で入力を適用し、k=6の測定と入力は次区間に向けた未適用の計算値です。終端では input_applied=false、next_state=null とし、7回目の更新を行いません。値0と未適用nullを混ぜません。

各行は k、true_state、source_index、source_value、noise、before_quantization、measurement、measurement_error=m−x、true_error=1−x、control_error=1−m、control_input、input_applied、next_state を保存します。今回gain1のためcontrol_errorとcontrol_inputは同じ値ですが、役割を分けます。全条件の初期値・全更新・終端を固定手表へ照合します。遅延の測定誤差は雑音0でも非零になり、量子化誤差も雑音とは別です。

## 検査と独立期待

有理数は正規化した分数字符列として保存します。手表は実装前に全28行と量子化9境界をliteralで固定します。計算実装は測定から入力、状態へ順に進み、別の検査は手表・代数的な入力消去・2×2行列の有限べき・量子化条件の閉形式を使います。

現在値ではk≥1でx=1/2であり、目標1への真の偏差は1/2残ります。目標を達成したとはしません。雑音条件では今回の係数1/2とgain1に限ってx[k+1]=(1−n[k])/2です。一般の係数へそのまま移しません。遅延条件では偏差e=x−1/2について e[k+1]=(e[k]−e[k−1])/2、e[−1]=e[0]=−1/2。量子化条件の今回6更新では x[2j]=(1−4^(−j))/3、x[2j+1]=2/3−4^(−j)/6 と手表を照合します。これらの有限関係から全ての遅延系・量子化系の安定性を保証しません。

入力は固定schema、4条件、初期履歴、目標、gain、係数、6更新、雑音列、量子化規約に限ります。不明な条件・余分/欠けたキー・異なる値・数値型bool/float・不正分数・不明な丸め方は状態更新前に拒否し、updates=0、成功表なしとします。UIの保存値は由来と固定入力も照合し、欠落・変更・古い別記録では古い図/答え/詳細を消します。
