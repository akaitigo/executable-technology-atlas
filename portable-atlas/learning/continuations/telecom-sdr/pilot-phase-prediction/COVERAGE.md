# Atlas — 通信の位相予測で今回埋める範囲

171受入（既存127＋独立44）の時点で目標66〜97の候補を照合し、目標95の phase-drift を選びました。元 `learning/subjects/telecom-sdr/README.md:74` と `coverage.json:17` に明示された、時間変化する位相へ一回の補正を使えるかという問いです。これは既存資料と受入一覧に基づく限定照合で、全ファイルに類似内容が存在しないと断定するものではありません。

既存の `pilot-quality-estimate-refusal` は pilot の大きさ/残差による推定拒否、`pulse-window-symbol-timing` は受信窓/ISIを扱います。今回の増分は、観測した2時点から後の位相を外挿する前提と、その前提が変わったときの判定結果です。既存の固定位相・品質拒否・窓処理は前提へ戻り、再制作しません。

固定4条件×2方式、2 pilot＋4 payload の全I/Qと誤り位置を対象にします。最初の pilot が欠落した場合、保持に必要な情報と外挿に必要な情報が異なることも示します。実行済みの範囲と現在状態は status.json、実行ログ、GUI-QA.mdへ分けて残します。契約時点では計算/実画面とも未実施です。

実無線機、GHz/Hzの計測、PLL、適応ループ、確率的雑音、統計BER、FEC、連続ストリームは未検証です。次は追加 pilot を配置して変化を検出する条件、または雑音下での推定不確かさを別の問いとして扱えますが、今回の4条件へ一般保証を加えません。
