# Atlas — 位相予測の判断に使う

このSkillは [README](README.md)から使います。保存結果を読む案内に限定し、無線機、外部API、ブラウザー、計算を自動起動しません。

1. 「pilotで合わせたのに後のbitが違う」なら、[画面](index.html)の一定回転を選び、受信I/Q→保持した係数→補正I/Q→判定の順に読みます。[手計算](HAND-CALCULATION.md)の残りの回転r..r⁴へ結びます。
2. 「2 pilotなら常に良いか」なら、途中反転を選びます。外挿器が知るのはn=0,1だけで、検査用channelを入力していないことを[契約](CONTRACT.md)で確認します。将来の方向変化は予測の前提を壊します。
3. 「最初のpilotが0なら0誤りか」なら、最初のpilot欠落を選びます。保持と外挿の必要な情報を比べ、外挿の判定/誤り数null・比較数0を読みます。0誤りの成功とは説明しません。
4. 「弱いpilot、受信窓のずれ、強い雑音も直るか」なら、[前提](PREREQUISITES.md)の品質拒否/受信窓教材へ戻ります。この4条件に品質・窓・雑音の性能を追加して説明しません。
5. 「この値が実際の無線機の性能か」なら、[原典との対応](SOURCE-MAP.md)と[COVERAGE](COVERAGE.md)へ案内します。単位複素数と厳密有理数の有限計算であり、実RF、Hz測定、PLL、一般BERの測定ではありません。

数値を答える前に status.json と保存計算の由来を確認します。計算結果が未保存、壊れている、別の条件なら推測で補わず、その状態を伝えます。実装・入力・手表を変更して見かけの成功へ合わせません。
