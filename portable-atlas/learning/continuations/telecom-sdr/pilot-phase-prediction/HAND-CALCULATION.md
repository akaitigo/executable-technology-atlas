# Atlas — 実装前の手計算の根拠

`r=(3+4i)/5`、`r*conj(r)=1`。以下は計算プログラムを実行する前に代数で固定した表です。全32行の I/Q は hand-oracle.json に保存しています。

| j | Re(r^j) | Im(r^j) |
|---|---:|---:|
| 0 | 1 | 0 |
| 1 | 3/5 | 4/5 |
| 2 | −7/25 | 24/25 |
| 3 | −117/125 | 44/125 |
| 4 | −527/625 | −336/625 |
| 5 | −237/3125 | −3116/3125 |

複素積で進む側では、実部/虚部を `(3a−4b)/5,(4a+3b)/5` へ1区間ずつ更新します。別の検査は `(3+4i)^j/5^j` を二項展開し、偶数項と奇数項を分けて求めます。補正値は実部 `ac+bd`、虚部 `bc−ad` という内積/外積から計算し、複素積の実装を再利用しません。

固定位相では両方式とも、補正後の4値は [1,−1,−1,1] です。

一定回転では保持の予測が r のままなので、正解の符号を除いた残りの回転は n=2..5 で r,r²,r³,r⁴。実部の符号は +,−,−,− です。正解 bit [0,1,1,0] の符号を掛けると判定は [0,0,0,1]、誤りは symbol 番号 [3,4,5]。外挿は実際の r²..r⁵ と一致し、判定は [0,1,1,0] です。

途中反転では channel が r²,r³,r²,r となります。保持の残りは r,r²,r,1 なので判定 [0,0,1,0]、誤りは [3]。外挿の残りは 1,1,r⁻²,r⁻⁴ で、判定 [0,1,0,1]、誤りは [4,5]。ここで回転の負のべきは共役なので実部の符号は正のべきと同じです。

最初の pilot が0のとき、保持は最新の r だけを使い一定回転と同じです。外挿には1区間差を求める最初の根拠がなく、係数/判定/誤り数は null、比較数0とします。

これらの誤り数は4個の固定 bit に対する比較です。確率的な誤り率や製品性能の測定ではありません。独立担当は本表とは別に全 I/Q を求め、実装前に期待を保存します。
