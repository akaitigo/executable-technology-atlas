# Atlas：サンプルの時刻換算と、二つのずれ

目標94と既存 media-codec-streaming の次実験 timebase-drift に対応する、実装前の契約です。PCM のサンプル数、時刻の単位、提示時刻、到着時刻を分けて読む既存経路の次に置きます。実デバイス、音質、実再生や RTP 通信の測定ではありません。

## 単位・原点・丸めを固定する

1サンプルは mono の1フレームとします。サンプル位置 N は先頭から N 個分だけ進んだ境界で、0始まりです。範囲は0から307200、区間数は0から300です。サンプル値や WAV のバイトを作りません。

名目の周波数は48000 sample/s。時刻の単位は ms、1秒=1000ms、サンプル0の原点は0msです。名目の正確な時刻は t=N/48 ms。区間長は各条件内で一定です。先頭境界を含む全境界を保存します。空の条件は境界0だけで、存在しない区間を加算しません。

非負の時刻 x は最も近い整数 ms へ丸め、ちょうど0.5なら大きい方にします。Q(x)=floor(x+1/2)。これはこの教材の表示・換算規約で、RFCの要求や Python の round の規則ではありません。丸め前の有理数と整数結果を両方残します。

- 絶対位置から換算：A(k)=Q(k×B/48)。毎回、原点からの合計サンプル位置に戻って丸めます。
- 各区間を丸めて加算：C(0)=0、C(k)=C(k−1)+Q(B/48)。B は1区間のサンプル数です。

時計差がなければ、どちらも同じ正確な t と比較します。A−t と C−t は丸め誤差です。A が常に無誤差という意味ではなく、今回の丸めによるずれが各境界で0.5ms以内に収まることを見ます。C の誤差は区間数に応じて蓄積し、符号は区間長と丸めによります。

## 時計の進み方の差を別の原因として置く

最後の条件だけ、サンプル時計が名目より100ppm速いと仮定します。ppm は100万分の1で、+100ppm は倍率10001/10000です。実機で測った値ではありません。基準時計は理想とし、原点のずれは0、速さの差は一定です。

この仮定で同じ N サンプルが進む基準時間は R=t×10000/10001。名目換算と基準時間の差 t−R を時計差、A−t / C−t を丸め誤差として分離します。全体の差は A−R=(A−t)+(t−R)、C−R=(C−t)+(t−R) です。浮動小数の揺れ、到着遅延、ジッター、時計の初期オフセットを原因として混ぜません。

## 実装前に固定する8条件

| 条件 | 1区間のサンプル B | 区間数 | 最終 t | 最終 A | 最終 C | 時計差 |
|---|---:|---:|---:|---:|---:|---|
| empty | 1024 | 0 | 0 | 0 | 0 | 0ppm |
| below-half | 23 | 1 | 23/48 | 0 | 0 | 0ppm |
| half-twice | 24 | 2 | 1 | 1 | 2 | 0ppm |
| above-half | 25 | 1 | 25/48 | 1 | 1 | 0ppm |
| exact-integer | 48 | 3 | 3 | 3 | 3 | 0ppm |
| thirds-three | 1024 | 3 | 64 | 64 | 63 | 0ppm |
| thirds-long | 1024 | 300 | 6400 | 6400 | 6300 | 0ppm |
| fast-clock | 1024 | 300 | 6400 | 6400 | 6300 | +100ppm |

時間の値はすべて ms です。最後の条件の R は64000000/10001、時計差は6400/10001。C の丸め誤差は−100、全体差は−993700/10001。相殺して小さく見える場合があっても、時計が直ったとは説明しません。

手表には各条件の最終値に加え、先頭・丸め境界・1024サンプルの3区間周期・長い条件の中間と末尾を固定します。producer は整数の商と余りで丸め、別の検査は Fraction と固定手表から全境界を照合します。手表を producer の出力から生成しません。

## 入力拒否と観測範囲

bool、負の値、非整数、周波数0、範囲外、知らない条件・単位・丸め方・時計差を拒否します。無効な入力に時刻列を返しません。保存した別条件・欠落・改変の表示も拒否し、前の成功結果と答えを消します。

Python標準ライブラリーの子1件で固定8条件と入力拒否を逐次計算します。直前の資源・競合確認、同じ子で nice10 の設定と実値確認、観測5秒と別の回収猶予2秒を条件にします。部分出力・終了・回収を保存し、不明なら追加起動しません。実時計を操作せず、新サービス、インストール、OS変更はしません。

読み順は予想→保存計算を操作して比較→RFC3550§5.1と実装→答え→限界・実務判断。RFC のサンプル時刻の概念を参照しますが、この模型を RTP 準拠実装とは呼びません。32bit wrap、ランダム初期値、RTCP同期、PTS/DTS一般、補正処理、負の時計差、可変レート、到着時刻、実音質は範囲外です。GUI・実DOM・画像は保留し、未実施なら教材全体の accepted は false に保ちます。
