# Atlas — 実装前の手計算

M=7では、A=2/5について M*z=14/5、Q=3、再構成3/7、誤差1/35です。B=7/15は M*z=49/15、Q=3、再構成3/7、誤差−4/105です。厳密にはAが手前でも整数値は同じです。A→Bなら両方式A、B→Aなら厳密A・整数Bが残ります。

M=15では AのQ=6、BのQ=7となり、再構成は元の2/5・7/15と一致します。どちらの順でもAが残ります。A=B=2/5なら厳密値も整数値も等しく、両方式で先に描いた面が残ります。

独立に整数jの丸め区間を見ると、内側のbinは `(j−1/2)/M ≤ z < (j+1/2)/M` です。端のbinは0..1へ切り詰め、最大binには許容域の端z=1も含めます。binへの所属と、strict LESSでその面を採用するかは別です。この区間所属を、商余りで計算する模型とは別に確認します。
