# Atlas — 測定した値で制御すると、次の状態はどう変わるか

同じ制御対象でも、現在の状態、1標本前の状態、雑音を加えた測定、丸めた測定では入力が変わります。その入力が次の状態へ戻ることを、4条件・6回の更新で比べます。ここでいう「真の状態」は模型の内部状態で、実機の真値を測ったものではありません。

[教材を開く](index.html) → [前提の要点](PREREQUISITES.md) → [原典との対応](SOURCE-MAP.md) → [質問から使うSkill](SKILL.md)へ進めます。保存値と画面の実施状況は[現在の状態](status.json)で確認できます。

## 読む順

1. k=1の測定値は同じ時点の状態と同じか、最後に表示する入力は適用済みかを予想します。
2. 保存した計算を開き、前後の時点へ動かします。カードは選択した時点、表と図は保存した全7境界です。
3. 現在値の条件を、1標本前・固定雑音・整数への丸めと比較します。参照番号、測定m、入力u、次の状態を別々に追います。
4. [初期履歴・丸め・終端の規約](CONTRACT.md)、[計算の実装](model.py)、[実装前の手表](hand-oracle.json)で根拠を確かめてから答えを開きます。
5. 実務では、記録が現在値か過去値か、加工された測定か、まだ適用していない入力かを確認します。今回の数字から機器の設定を決める教材ではありません。

## 四つの比較

模型は入力u=1−m、次の状態x=(今のx+u)/2です。係数1/2と比例ゲイン1を固定し、測定経路だけ変えます。単位は架空の無次元値、時刻kは標本番号です。

| 条件 | 何を変えるか | 手表で先に固定したk=1の対照 |
|---|---|---|
| 現在値 | 今の状態をそのまま使う | x=1/2、m=1/2、u=1/2 |
| 1標本前 | x[−1]=0を初期履歴とする | x=1/2でもm=0、u=1、次のx=3/4 |
| 固定雑音 | 測定にだけ+1/4,−1/4,…を加える | x=3/8、m=1/8、u=7/8 |
| 整数へ丸める | ちょうど半分は0から遠い整数へ | x=1/2をm=1へ丸め、u=0、次のx=1/4 |

測定と状態の差m−x、目標と状態の偏差1−x、制御器が見た偏差1−mを区別します。現在値条件でも真の偏差1/2は残ります。終端k=6では測定と入力を計算しますが、入力は未適用で次の状態はnullです。7回目の更新はありません。

## 再現と保存値の検査

既存Pythonの標準ライブラリだけを使います。[実行条件](CLI-POLICY.md)に従う資源確認と今回の枠が成立した場合だけ、[run.py](run.py)から1つの子で計算します。実行時間は5秒、別の回収猶予は2秒、実nice値10、自動再試行は0です。通常の読取りでは[verify.py](verify.py)で保存結果を手表と別の代数式へ照合し、計算を再実行しません。

```sh
python3 -B verify.py observations/calculation-20261006T231426766871Z
```

画面をローカルで配信する場合は、このディレクトリで `python3 -B serve.py --port 0` を使います。127.0.0.1だけで静的ファイルを読み、Markdownを本文として表示します。この手順自体は計算やブラウザーを起動しません。今回の画面確認も既存の同じページを使い、新しいブラウザーやタブは起動していません。

## 既存との違いと限界

[前提](PREREQUISITES.md)から、比例制御、数値法と入力保持、PIと飽和、ロボットの観測遅延、測定の偏りとばらつきへ戻れます。今回の焦点は、測定を加工した結果が入力へ戻り、次の状態を変える時系列です。これらの既存原理を新しい成果として数え直しません。

[範囲](COVERAGE.md)と固定契約は実装前の版を保持しています。そこに記載した当時の未実施状態と、現在のstatusを分けて読みます。任意ゲイン・周期、複合要因、確率的雑音、校正、推定器、一般安定性、実機性能・安全性は未検証です。図の線は標本点を結ぶ表示で、標本間の測定や連続時間軌道ではありません。外部前提へのファイルリンクの実在確認と、専用のHTTP配信から辿れることも別の確認です。
