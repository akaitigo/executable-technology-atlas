# Atlas — 扱う範囲と次に残る問い

目標53の「調査に必要な証拠・費用・保持範囲を決める」ため、区間件数に圧縮した後で分位点をどこまで知れるかを扱います。

| 範囲 | 今回の固定比較 | 境界 |
|---|---|---|
| 生データ | 既存 nearest-rank を答え合わせに再利用 | 欠落/遅着/母集団推定は前教材の範囲 |
| 情報の損失 | 同じ区間件数で raw 分位点が違う A/B | 元の列を集約値から復元しない |
| 解像度 | A を粗い区間と細かい区間へ集約 | 任意分布の誤差改善や最適な区切りを保証しない |
| 境界 | 0/10/20/40 と q=0,1/2,3/4,1 | 無限区間・負値・浮動小数の境界を網羅しない |
| 空 | n=0 は区間/分位点/推定を null | 0msの結果と区別する |
| 補間 | 宣言した線形式を Fraction で計算 | 製品互換/全方式の比較/確率的信頼区間ではない |

固定20組の計算は1回保存済みです。作者の保存値検査161関係と8改変拒否を確認しました。入力schemaの拒否を実行で網羅した結果ではありません。保存結果readerの実操作で20組・13切替状態・5つの失敗/古い応答を確認し、9実画面を保存しました。最終独立受入は [確認状態](qa/reader-acceptance.json) から辿れます。390pxでは図と比較表を左右に分けて読み、図0→348→0、比較表0→498→0の実横移動を確認しました。右端では左の見出しや条件名、今回の値の点が画面外になります。全内容が同時に見えるという確認ではありません。

一般 sketch、実 collector、OTel/Prometheus の適合、観測窓の集約、SLO/alert、計測負荷・保存費用の実測は未対応です。既存180件の再実装・再計算や共有統合は行いません。
