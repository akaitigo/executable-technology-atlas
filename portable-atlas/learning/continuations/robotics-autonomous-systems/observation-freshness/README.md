# Atlas — 新しく届いた観測は、新しい情報？

障害物を見た後に、古い「空き」が届く。到着順のまま地図を書き換えると、何を失うでしょう。5つの合成観測列で、観測時刻・到着時刻・採用version・期限を分けます。図は保存計算の説明であり、実sensorの表示ではありません。

先に[点gridのmapとworld](related.html?doc=base)を読みます。[footprint](related.html?doc=footprint)と[制動距離](related.html?doc=braking)は既にある前提です。ここでは幾何や移動計画を作り直さず、固定した次edgeの対象cellの知識だけを調べます。

## 画面で読む順

1. [学習画面](index.html)の条件ボタンで到着列を選び、最後の時点の保守版が移動候補を許すか、占有で止めるか、不明で止めるかを予想します。
2. 「保存した計算を再生」を押し、時点ボタンで到着した観測と採用後の知識を読みます。
3. 保守版と無条件上書きを比較します。観測versionと更新回数、到着観測のageと保持観測のageはそれぞれ別です。
4. [原典対応](SOURCES.md)と保存した実装を読み、答え合わせで判断に使った条件を確認します。
5. [Skillの3問](SKILL.md)から、実務で時刻・順序・unknownについて追加すべき条件を考えます。

5列15時点×2方式の30応答を実Pythonで1回計算しました。保存JSONの1,304関係と9改変拒否を確認しました。実画面でも15時点の30応答、12の状態変化と5つの取得失敗・古い応答の対照を保存し、1280/390幅の9画像ファイル（8種類）を記録しました。[確認状態](qa/reader-acceptance.json)を参照してください。画面は保存結果のreaderで、操作のたびに模型や実robotを実行するものではありません。

## 開き方と限界

教材内で `python3 -B serve.py --port 0` を実行すると `ATLAS_PORT=番号` が出ます。`http://127.0.0.1:番号/` を開きます。保存資料を配信するだけで、模型は実行しません。今回の画面確認は共通の1ページを再利用しました。検査環境が教材用loopback serverを1個起動して終了し、検査module自身のbrowser/context/page/server起動は0です。

[契約](CONTRACT.md)、[固定入力](cases.json)、[手追跡](expected.json)、[再現](REPRODUCE.md)、[既存との違い](reuse-and-scope.md)、[対応範囲](COVERAGE.md)を辿れます。MOVE_ALLOWEDはこの模型の知識上の候補判断であり、実worldがfree、実移動した、安全に止まれる、という証拠ではありません。

狭幅では図・表を横に動かして読みます。右端では方式名・位置や表の時刻列などが画面外になり、すべてを同時には読めません。[画面確認記録への参照](qa/reader-acceptance.json)に保存値・操作・画像の範囲を分けています。契約と手追跡は実装前に固定した版で、現在の実施状況は確認状態から辿ります。
