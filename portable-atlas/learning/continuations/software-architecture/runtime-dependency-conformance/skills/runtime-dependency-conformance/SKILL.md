# runtime dependencyと責務

このmoduleだけで使用する。任意module import、元Subject/Portal変更、一般architecture適合保証に拡張しない。

1. README/oracle.jsonでroot選択・生成、core port呼出し許可の契約を読む。
2. python3 -B route.py inspect で独立literal source/trace/出力/責務表へ照合。
3. python3 -B route.py lesson で4fixture・trace-off・拒否・EXECUTION_FAILUREを比較。
4. 同じ業務辺を禁止辺にせず、実constructor/dynamic import callerで判断。trace欠落は判定不能。
5. 明示再実行依頼がある場合のみ python3 -B route.py record。通常checkは原票を更新しない。

実行失敗から正常答えを作らない。fixture外のmoduleをimportしない。
