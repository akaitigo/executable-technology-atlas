ROMに初期値があれば、RAMも正しい？

保存したPython計算を読み、配置先と初期化の処理を分けます。ROM/RAMは各16 byteの架空配列です。実マイコンの起動やリンカーによる配置は測定していません。

dataは初期値を持つ領域、bssは0で始める領域です。mainはそれらを利用し始める処理の読取り役、guardは越境を見つける保護用byteです。

A5とCCは見分けるための合成値で、電源投入時の実RAM値ではありません。
