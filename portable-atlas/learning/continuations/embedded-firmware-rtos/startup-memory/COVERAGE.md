# Atlas — 起動メモリー教材の範囲

最新162教材（既存127＋独立35）から、目標86の前提不足を選んだ。元embedded README:63と目標文書:1007は架空memory mapと起動初期化を次課題として挙げる。ISR/共有更新、offload queue、priority、Tiny8命令実行、buildの未宣言入力は既存範囲として差し引いた。

| 学べる判断 | 有限な確認対象 |
|---|---|
| ROMの保存場所とRAMの利用場所を分ける | LMA/VMAを領域とoffsetで対照 |
| 配置と初期化処理を分ける | dataコピー、bssゼロ化の省略 |
| 不要な順序制約を作らない | 非重複ならcopy/zero両順とも正常 |
| 最終値だけで過去を判断しない | 早期mainの読値と後のRAM |
| 変数値が合っても越境を見落とさない | 全write、全RAM、保護用byte |
| 空の処理を4 byte初期化と混同しない | 長さ0、write0、空の読値 |

現在は契約と手期待を固定する段階。対象計算・実画面は未実施。現在状態は後でstatus.jsonへ分離し、この実装前文書は履歴として保持する。

後続の不足は実reset/stack・constructor・linker配置の生成、HAL/device依存、実機の測定。原担当の現在の活動は未確認で、共有元への統合は保留。分野全体の完成や全体台帳への加算を意味しない。
