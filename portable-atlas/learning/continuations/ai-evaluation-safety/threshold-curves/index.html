5　実務の問いと、この教材の限界
陽性集合は閾値を下げるほど広がりますが、Precision が必ず下がるわけではありません。ROC と PR は分母と軸が違います。見逃しと誤警報のどちらを重く見るかは、用途と損失を別に考える必要があります。
全陰性では Precision の分母が0です。この教材は未定義を保持し、PR の (0,0) や (0,1) へ補いません。同 score の陽性と陰性を閾値だけで別々に取り出すこともできません。
合成 score の計算が合っていても、学習済みモデルの性能、確率較正、実世界での汎化、公平性、安全性は証明しません。既存 Brier 教材や旧少数閾値の実績は再加算しません。
