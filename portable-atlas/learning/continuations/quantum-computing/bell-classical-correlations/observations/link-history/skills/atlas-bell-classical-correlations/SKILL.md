# 使用

Bell、mixture、partial-trace、joint-probability、basis、coherence、branch-averageの問いを受けたら[README](../../README.md)と[UI](../../index.html)を読み、単元ディレクトリで`python3 verify.py`を実行する。既存[route.py](../../route.py)のroute(topic)で対応範囲を確認する。初回記録を上書きしない。

Z一致・X差・局所I/2を区別し、誤った枝平均のtrace拒否と再正規化後の意味不一致を説明する。[coverage](../../coverage.json)と[source locator](../../sources.json)で未教材へつなぐ。実機・量子優位性・一般entanglement判定の依頼はこの単元では未対応と明示する。依存追加、クラウド、旧教材変更を行わない。
