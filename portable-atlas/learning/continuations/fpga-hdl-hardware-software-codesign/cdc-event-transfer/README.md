# Atlas — 別クロックへ事象は届く？

送った1回と、受け取った1回は同じとは限りません。短いpulse、保持したlevel、反転を記憶するtoggleを、5つの小さな理想0/1模型で比べます。2FFの論理を追う教材であり、実FPGAのmetastabilityやタイミングを測るものではありません。

先に[counterの旧値更新](related.html?doc=counter)、[ready-validの保持と捕捉](related.html?doc=ready-valid)を読みます。保持できることと別clockで確実に検出できることを分けるのが今回の問いです。

## 画面で読む順

1. [学習画面](index.html)で条件ボタンを押し、宛先の最終検出数を0・1・2から予想します。
2. 「保存した計算を再生」を押し、時刻ボタンでsampleとff1/ff2/historyを読みます。すべてのregisterは旧値から同時更新します。
3. 短pulseと保持level、1toggleと近接2toggleを比較します。t=9で出力が1のままsourceが進んでも、宛先の検出数は増えません。
4. [原典と模型の対応](SOURCES.md)と画面の実装表示を読み、最後に答え合わせを開きます。
5. [Skillの3問](SKILL.md)で、何を実務の設計条件として追加確認すべきかを説明します。

画面は保存結果のreaderです。操作で新しい回路や模型を実行しません。時間の図は保存した整数時系列の説明図であり、測定器の波形ではありません。5条件・100時点（宛先35時点）を実Pythonで1回計算し、保存JSONを1,960関係と8改変で検査しました。別担当の手表による1,861関係と4改変の検査も通過しています。両検査には重複があるため合算しません。既存の1ページで100時点、5条件、表示変更12状態、取得失敗・古い応答5対照を確認し、1280/390幅の9画像を保存しました。別担当が画像を1枚ずつ確認しました。[確認状態](qa/reader-acceptance.json)を参照してください。

## 起動と読む資料

既存Pythonだけで `python3 -B serve.py --port 0` を実行すると、`ATLAS_PORT=番号` が出ます。`http://127.0.0.1:番号/` を開きます。配信は保存ファイルの読取だけで、模型を動かしません。画面検査は共通の1ページを再利用しました。検査環境がこの教材の配信serverを1個起動し、確認後に終了しました。検査module自身のbrowser/page/server起動は0です。

[固定入力と規約](CONTRACT.md)、[手時系列](expected.json)、[再現の区別](REPRODUCE.md)、[対応範囲](COVERAGE.md)、[既存との違い](reuse-and-scope.md)から根拠を辿れます。未検出の遅延はnullです。宛先が送信件数を知っていると解釈しないでください。
