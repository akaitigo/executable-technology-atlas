# 制作と受入の順序

1. 契約・6入力・手表を固定し、独立担当がproducer未読で期待を保存する。
2. 独立照合後、stdlibの2方針模型・1batch出力・保存値だけの検査を制作する。未知fieldのrawを出力しない。
3. rootへcommand/sourcehashを渡す。fresh資源/単独枠で1子nice10/wall5秒。作者は模型を起動しない。
4. 保存実測を手表へ照合しreaderへbyte結合。READMEから前提/原典/Skillへ辿る。失敗/未実行を実測へ置換しない。
5. root提供pageだけで全時点DOM/2幅画像/資料を確認。条件/方針/予想/resetと遅延応答の消去、保存値不正のfail-closedを確認する。
6. 独立受入→可変status読み戻し。共有元や集計は編集しない。
