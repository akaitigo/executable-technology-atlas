# Atlas ローカル教材 — 移行用コピー

予想を立て、条件を操作し、正常・異常を比べ、原典と実装から答え合わせする教材です。分野一覧は97項目ですが、全知識の網羅や分野完成を意味しません。

既定の一覧は、従来の中央統合 **142教材** です。全 **191教材** の実装・説明・テストを選別して収録しています。148への候補に含まれる追加6教材と、その他の未統合43教材は `review/` に分離しています。これは選別した移行コピーであり、全教材producer・GUIの新しい環境での受入は未完了です。

Node.js 22.13以上があれば、依存パッケージのインストールなしで保存readerを起動できます。

```sh
node scripts/local-learning-preview.mjs
```

表示された `http://127.0.0.1:...` を開きます。自動でブラウザを開きません。終了は起動したterminalで Ctrl+C を押します。外部ホストへの公開設定はありません。

- `/`：正式142の一覧
- `/review/candidate148`：追加6教材。中央受入前
- `/review/pending`：その他の未統合43教材

保存readerは過去のデータを読みます。専用APIやcompiler等の新規実験は起動しません。教材のモデル・固定入力・期待値・Skillを確認し、実験の前提を満たしたものだけ個別に実行してください。

私的な実行履歴、端末情報、旧管理文書、未確認の画像・バイナリは同梱していません。加工したテキストは元の原票とはSHAが異なります。古い証拠のdigest、GUI検証、受入を、このコピーの検証に読み替えないでください。未同梱データに依存するreaderや検査は未復旧として残しています。

[別PCへの復元](docs/RESTORE.md)・[配置と隣接7repo](docs/SETUP.md)・[再開メモ](docs/RESUME.md)・[収録ファイル](app/lib/migration-files.json)・[191教材の区分](app/lib/migration-lessons.json)を参照してください。

```sh
npm test
```

この検査は一覧の区分、参照境界、文書・source応答を対象とします。ブラウザ・専用API・全教材producerの再実行ではありません。

修復した4教材は、配布用の保存再生を局所JS検査しています。原本の受入・新規計算・GUI受入とは区別します。

非秘密のSQLite seedと入力索引は [再生成手順](docs/REGENERATION.md) にあります。seed検査はPython 3.9以上を使う `npm run test:seeds` で、保存readerの `npm test` とは分けています。
